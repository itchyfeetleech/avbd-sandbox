How to play

Mouse and touch

Grab toolDrag an object to pull it through the world. Drop toolClick or paint to add single objects. Shift+drag works from any tool. Throw toolClick a point to fire the selected rigid shape toward it. Erase toolClick any movable body to remove it. CameraDrag empty space to orbit; right-drag to pan; scroll or pinch to zoom.

About

An implementation of Augmented Vertex Block Descent by Giles, Diaz, and Yuksel (SIGGRAPH 2025), written from the paper, with a CPU engine and a parallel WebGPU backend. Read the project page .
